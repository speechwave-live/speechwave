### Task 3: Deploy workflow

**Files (in `/Users/tracy/projects/speechwave-live/docs`):**
- Create: `.github/workflows/deploy.yml`

**Interfaces:**
- Consumes: repo secrets `DREAMHOST_HOST`, `DREAMHOST_USERNAME`, `DREAMHOST_PASSWORD` (added manually by Tracy; names only, never values).
- Produces: deploy-on-push-to-main pipeline used by Task 4.

- [ ] **Step 1: Write the workflow**

`.github/workflows/deploy.yml`:

```yaml
name: Deploy docs to DreamHost

on:
  push:
    branches:
      - main
  workflow_dispatch:

jobs:
  deploy:
    runs-on: ubuntu-latest

    steps:
      - name: Checkout repository
        uses: actions/checkout@v5

      - name: Setup Ruby
        uses: ruby/setup-ruby@v1
        with:
          ruby-version: "3.4"
          bundler-cache: true

      - name: Build Jekyll site
        run: bundle exec jekyll build
        env:
          JEKYLL_ENV: production

      - name: Deploy to DreamHost via SFTP
        uses: wlixcc/SFTP-Deploy-Action@v1.2.4
        with:
          server: ${{ secrets.DREAMHOST_HOST }}
          username: ${{ secrets.DREAMHOST_USERNAME }}
          password: ${{ secrets.DREAMHOST_PASSWORD }}
          port: 22
          local_path: './_site/*'
          remote_path: '/home/${{ secrets.DREAMHOST_USERNAME }}/docs.speechwave.live/'
          delete_remote_files: false
          sftp_only: true
```

Note the `remote_path` derives the home directory from the Dreamhost username — Dreamhost's default web directory for a fully hosted subdomain is `/home/<user>/<subdomain>/`. Task 4 confirms this path with Tracy before the first deploy.
